# VRCColliderProbe

VRChat のワールドを OSC で自動歩行し、**床コライダーの張り忘れ（床抜け）**や**コライダーの隙間に挟まる場所**を探して、
地図付きの報告にまとめるツールです。発想はルンバ（壁に当たったら曲がり、落ちたら記録する）。

> **非公式ツールです。** VRChat Inc. とは関係がなく、VRChat による確認や承認を受けたものではありません。

## できること

- **自動歩行**：OSC で前進・旋回し、壁に詰まったら向きを変える。低い段差はジャンプで乗り越える
- **落下の検知**：段差・リスポーン（ワールドの外への落下）・挟まり（落下状態のまま動けない）を見分けて記録する
- **地図**：OSC の速度と旋回から位置と高さを推定し、歩いた範囲・壁・落下地点を地図にする（2D と 3D）
- **探索**：歩いていない場所を優先して歩く。同じワールドで走るたびに記録が積み上がり、続きから探索する
- **巡回**：GUI で地図を塗って範囲を決め、その中をまんべんなく回り続ける（地図がそろったワールド向け）
- **ナビ**：自分で歩くときに、ワールドの地図と今の位置、行き先までの道をミニマップに出す（入力は一切送らない）
- **報告**：走行ごとに 1 枚の HTML（地図・落ちる瞬間の画面・見つけたもの）を作る
- **オーバーレイ**：VRChat の画面の右上に、ルートと作りかけの地図をリアルタイムに重ねる（録画にも写る）
- **（任意）画面の解析**：[RelateAnything](https://github.com/Maelic/RelateAnything) を使うと、落ちた場所の状況説明
  （「アバター は ledge の上にいる」など）や「どこに何があるか」の地図を作れる

## 使い方の前提（必ず読んでください）

- **自分や仲間のワールドのデバッグ用**です。**プライベートインスタンスか Build & Test** で、
  **人が見ている状態で**使ってください。知らない人がいるインスタンスや公開インスタンスでは使わないでください
- 報告にはワールドの画面キャプチャがたくさん入ります。他の人のワールドを走らせたら、報告は作者本人と共有するだけにし、
  公開するときは作者の了解を取ってください
- 走らせる前に、VRChat の設定で**ポータルに入るには追加の操作が要る**ようにしておくと、うっかり別のワールドへ飛びません
- VRChat の利用規約を守って使ってください（OSC は VRChat 公式の仕組みですが、使い方の責任は使う人にあります）

## 必要なもの

- Windows 10 2004 以降（画面の撮影とオーバーレイに Win32 API を使う）
- VRChat（デスクトップモード）。**OSC を有効に**しておく（アクションメニュー → Options → OSC → Enabled）
- Python 3.12 以上と [uv](https://docs.astral.sh/uv/)

## セットアップ

```bash
git clone <このリポジトリ>
cd VRCColliderProbe
uv sync
```

## 使い方

### GUI（おすすめ）

```bash
uv run tools/gui.py
```

ブラウザで http://127.0.0.1:8790/ が開きます（自分の PC からしか開けません）。
走る時間やオプションを選んで「開始」、止めるときは「停止」。走行中の状況、ワールドの累計の地図、過去の報告を見られます。

巡回するには、地図の上で「塗る」を選んで範囲をなぞり、名前を付けて「範囲を保存」します。
走行の「動き方」で「巡回: <名前>」を選んで開始すると、その範囲の中を回り続けます。

ナビで使うには、「動き方」で「ナビ（自分で歩く）」を選んで開始し、スポーン地点から自分で歩きます
（途中から始めた場合はリスポーンすると位置が合います）。行き先は、地図の「行き先」モードでクリックするか、
見つけたものの一覧から選びます。ミニマップと GUI の地図に、行き先までの道が出ます。

### コマンドライン

```bash
# スポーン地点から 3 分歩く（先に VRChat でリスポーンしておく）
uv run tools/walker.py --duration 180 --overlay

# RelateAnything の表示も重ねる
uv run tools/walker.py --duration 180 --overlay --relate-overlay
```

止めるときは ESC（または Ctrl+C）。止め方にかかわらず、全入力を 0 に戻してから終わります。
結果は `runs/<日時>/` に出て、報告は `runs/<日時>/report.html` です。

主なオプション：

| オプション | 内容 |
|---|---|
| `--duration 秒` | 歩く時間（既定 300） |
| `--overlay` / `--overlay-size px` | 右上にミニマップを重ねる / その大きさ（既定 520） |
| `--relate-overlay` | RelateAnything の検出枠と状況説明を重ねる（GPU を使う） |
| `--not-at-spawn` | スポーン地点以外から始める（最初のリスポーンより後が地図に載る） |
| `--fresh` | ワールドの記録を使わず、記録にも加えない（スポーン地点が複数あるワールドなど） |
| `--no-climb` | 壁をジャンプで乗り越えようとしない |
| `--patrol ファイル` | GUI で保存した範囲（`worlds/<ワールドID>/patrols/<名前>.json`）の中を巡回する |
| `--navi` | ナビモード（入力を送らず、自分で歩く位置と地図をミニマップに出す） |
| `--hide-overlay-from-recording` | オーバーレイを録画・スクリーンショットに写さない |

そのほかのツール：

```bash
uv run tools/world.py                 # 今いるワールド（VRChat のログから）
uv run tools/knowledge.py             # 記録のあるワールドの一覧
uv run tools/report.py runs/<日時>    # 報告を作り直す
uv run tools/osc_probe.py             # OSC の疎通確認（受信した値を表示し、キーで動かす）
```

## 仕組みと限界

- 位置は OSC の速度（`VelocityMagnitude` / `VelocityX/Z`）と旋回（`AngularY`）の積分による推定で、**数 m ずれます**。
  リスポーンのたびにスポーン地点を基準に戻します
- 「外周から落ちた」か「床抜けか」は、落ちた地点の周りに歩いた床があるかで機械的に判定しています。
  **誤判定が混ざるので、報告の「要確認」の地点は、落ちる瞬間の画面で確かめてください**
- 高さは縦の速度の積分で、段差を上るときなどは低めに出ることがあります
- 設計の詳細と、実機で確かめた OSC の挙動は [SPEC.md](SPEC.md) にあります

## RelateAnything との連携（任意）

`--relate-overlay` や、報告の画面解析（状況説明・「どこに何があるか」）を使う場合だけ必要です。

1. [RelateAnything](https://github.com/Maelic/RelateAnything) を別のフォルダに用意し、その手順どおりに環境（torch 入り）を作る
2. 場所が `E:\AIProject\RelateAnything` 以外なら、環境変数 `RELATE_ANYTHING_ROOT` にそのフォルダを設定する
   （Python は `<そのフォルダ>\.venv\Scripts\python.exe`。別の場所なら `RELATE_ANYTHING_PYTHON` で指定）

このリポジトリには RelateAnything のコードもモデルも含まれていません。使う場合は、次の条件に従ってください。

- RelateAnything のコード：Apache-2.0
- 検出器（ultralytics / YOLOE）：**AGPL-3.0**
- RelSGG のモデルの重み：Meta の **DINOv3 ライセンス**
- 検出器が使う Apple MobileCLIP の重み：Apple のライセンス（再配布不可）

RelateAnything がない場合、これらの機能は使えませんが、歩行・地図・報告はそのまま動きます。
